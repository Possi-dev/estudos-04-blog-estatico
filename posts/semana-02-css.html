CSS: flexbox e grid mudam tudo

Julho 2026

Antigamente, centralizar uma <div> era uma tarefa complicada. Hoje, com flexbox, é trivial.

Flexbox em ação

.container {
    display: flex;
    justify-content: center;
    align-items: center;
    gap: 1rem;
}

Responsividade com media queries

Nem todo mundo acessa sites em telas grandes. Media queries adaptam o layout:

@media (max-width: 600px) {
    nav { flex-direction: column; }
}

O que aprendi

  • Flexbox resolve 90% dos layouts
  • Media queries para mobile-first
  • CSS custom properties (variáveis) evitam repetição
  • Transições e animações dão vida ao design
