O que aprendi na primeira semana de HTML

Julho 2026

O HTML (HyperText Markup Language) é a espinha dorsal de qualquer site. Na primeira semana, aprendi os fundamentos:

Estrutura básica

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
</body>
</html>

Tags semânticas

Em vez de usar <div> para tudo, HTML5 trouxe tags com significado:

  • <header> - cabeçalho
  • <nav> - navegação
  • <main> - conteúdo principal
  • <section> - seção temática
  • <article> - conteúdo independente
  • <footer> - rodapé

Links e navegação

A tag <a> não serve só para links externos. Com href="#id" você cria navegação interna na página.

Foi uma ótima primeira semana. Ver uma página surgir no navegador é recompensador!
