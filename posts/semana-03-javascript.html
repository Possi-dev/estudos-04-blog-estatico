JavaScript: o cérebro do site

Julho 2026

HTML é a estrutura, CSS é a aparência, e JavaScript é o comportamento. É o que transforma uma página estática em algo interativo.

Manipulação do DOM

const title = document.getElementById('title');
title.textContent = 'Novo título!';

Eventos

button.addEventListener('click', () => {
    alert('Botão clicado!');
});

Arrays e iteração

const frutas = ['maçã', 'banana', 'uva'];
frutas.forEach(fruta => console.log(fruta));

O que aprendi

  • DOM: como JS enxerga e modifica a página
  • Event listeners: reagir a cliques, teclas, envios
  • Arrays e métodos como map, filter, find
  • localStorage: salvar dados no navegador
